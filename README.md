# Evora landing page UI

## Run it
1. Extract the ZIP (if using the ZIP).
2. Open `index.html` in Chrome, Edge, or another modern browser.

## Included
- Responsive layout for desktop, tablet, and mobile
- Mobile navigation toggle
- Log In and Sign Up modal forms with basic front-end validation
- Informational navigation dialogs
- CSS-built laptop illustration, floating cards, stars, orbits, and purple glow

## Important
This is a front-end demo. The login/signup forms validate input in the browser only; they do not create accounts or authenticate users. Connect the form submit handler to a secure backend and database before using it in production.
